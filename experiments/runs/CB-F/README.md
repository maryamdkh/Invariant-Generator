# CB-F: CB2001, structure recovery (from CB-A)

`experiments/probes/cb_structure_recovery.py` (output
`experiments/outputs/structure_recovery_cb2001.json`): the true J2^0 and
J3^0 are fitted exactly onto the 29 monomials the encoder reads, then
compared with the learned raw rows. n = 2 (true 2). J1 vs J2^0: cosine
0.99999993, coefficient error 3.7e-4. J2 vs J3^0: cosine 0.999994,
coefficient error 3.4e-3. Structure score = the smaller cosine.

Data convention: CB2001 was generated by applying the criterion to the
stored columns directly (y matches criterion(X) to 6e-16), although the
file is labelled mandel_3d; the probe uses the columns as stored.
